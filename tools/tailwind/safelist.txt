The Safelist is a workaround for Tailwind's JIT mode not currently supporting a safelist.

Any whole text string in this file will have its class generated by Tailwind. Unfortunately, this workaround
does not support regex or partial completion, so the strings must be fully qualified.
They must also include the prefix (c-, o-, or u-).
See this thread for info: https://github.com/tailwindlabs/tailwindcss/issues/4029
